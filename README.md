# Sistem-Manajemen-Studio-Pilates
Aplikasi "Manajemen Sistem Studio Pilates" dikembangkan menggunakan pendekatan pemrograman prosedural terstruktur dengan bahasa C++, di mana seluruh fungsionalitas sistem diorganisasikan ke dalam blok-blok fungsi yang terpisah secara modular dan jelas. Struktur ini diterapkan agar alur eksekusi program lebih teratur, mudah dibaca, serta memudahkan proses pemeliharaan dan pengembangan fitur di masa mendatang.
